# 政策智能系统部署指南

## 系统概述

政策智能系统为企业用户提供自动化的税务政策采集、检索、匹配和通知服务。

### 核心功能

1. **政策采集** - 从官方渠道自动采集最新税务政策
2. **语义检索** - 基于向量相似度的智能政策搜索
3. **企业匹配** - 根据企业画像自动推荐相关政策
4. **智能通知** - 新政策自动推送至相关企业

## 快速开始

### 1. 数据库迁移

确保已执行数据库迁移：

```bash
cd rag_backend
alembic upgrade head
```

迁移将创建以下表：
- `policies` - 政策主表
- `policy_relations` - 政策关联关系表
- `enterprise_policy_matches` - 企业政策匹配表
- `update_history` - 更新历史表

### 2. 安装依赖

```bash
pip install beautifulsoup4  # 如未安装
```

### 3. 启动调度器

在应用启动后，调用调度器启动接口：

```bash
POST /api/v1/policy/scheduler/start
```

或自动启动（需在配置中启用）：

```python
# 在应用启动时自动启动
@app.on_event("startup")
async def startup_event():
    from app.services.policy_scheduler import policy_scheduler
    await policy_scheduler.start()
```

## API 使用指南

### 1. 政策搜索

**请求示例：**

```bash
POST /api/v1/policy/search
Content-Type: application/json

{
  "query": "研发费用加计扣除政策",
  "top_k": 10,
  "filters": {
    "industries": ["制造业"],
    "tax_types": ["企业所得税"]
  }
}
```

**响应示例：**

```json
{
  "results": [
    {
      "policy_id": "xxx-xxx-xxx",
      "title": "关于完善研发费用税前加计扣除政策的公告",
      "summary": "进一步激励企业加大研发投入...",
      "score": 0.92,
      "source_name": "国家税务总局",
      "published_date": "2024-01-15",
      "priority": "high",
      "industries": ["制造业", "科技"],
      "tax_types": ["企业所得税"]
    }
  ],
  "total": 1,
  "query": "研发费用加计扣除政策"
}
```

### 2. 企业政策匹配

**请求示例：**

```bash
POST /api/v1/policy/match
Content-Type: application/json

{
  "industry": "制造业",
  "region": "北京",
  "scale": "大型企业",
  "tax_types": ["增值税", "企业所得税"]
}
```

**响应示例：**

```json
{
  "results": [
    {
      "policy_id": "xxx-xxx-xxx",
      "title": "关于完善增值税政策的公告",
      "score": 0.87,
      "match_reasons": [
        "适用于制造业行业",
        "在北京市适用",
        "涉及相关税种: 增值税, 企业所得税"
      ]
    }
  ],
  "total": 1,
  "query": "企业匹配"
}
```

### 3. 获取最近政策

```bash
GET /api/v1/policy/recent?days=7&top_k=20
```

### 4. 手动触发采集

```bash
POST /api/v1/policy/collect
Content-Type: application/json

{
  "keywords": ["税务", "优惠政策"]
}
```

### 5. 调度器配置

**获取状态：**

```bash
GET /api/v1/policy/scheduler/status
```

**配置调度器：**

```bash
POST /api/v1/policy/scheduler/config
Content-Type: application/json

{
  "frequency": "daily",
  "keywords": ["税务", "税收优惠"],
  "enabled_sources": ["国家税务总局", "财政部"],
  "time_of_day": "03:00"
}
```

**启动/停止调度器：**

```bash
POST /api/v1/policy/scheduler/start
POST /api/v1/policy/scheduler/stop
```

### 6. 通知管理

**获取企业通知：**

```bash
GET /api/v1/policy/notifications/{enterprise_id}?status=pending&limit=20
```

**确认通知：**

```bash
POST /api/v1/policy/notifications/{notification_id}/acknowledge
Content-Type: application/json

{
  "feedback": {
    "relevant": true,
    "action_taken": "已查看"
  }
}
```

**忽略通知：**

```bash
POST /api/v1/policy/notifications/{notification_id}/dismiss
Content-Type: application/json

{
  "reason": "与本企业无关"
}
```

### 调度器频率选项

- `hourly` - 每小时执行
- `daily` - 每天执行（默认）
- `weekly` - 每周执行

3. **国务院** (gov.cn) - 优先级: 3

## 故障排查

### 常见问题

**1. 政策采集失败**

```bash
# 检查网络连接
curl -I https://www.chinatax.gov.cn

# 检查 robots.txt 规则
curl https://www.chinatax.gov.cn/robots.txt

# 检查限流状态
GET /api/v1/policy/scheduler/status
```

**2. 检索性能下降**

```sql
-- 检查索引
SELECT * FROM pg_indexes WHERE tablename = 'policies';

-- 重建索引
REINDEX TABLE policies;
```

**3. 通知未发送**

```bash
# 检查待处理通知数量
GET /api/v1/policy/notifications/{enterprise_id}?status=pending

# 手动触发批量处理
POST /api/v1/policy/notifications/batch-process
```

## 安全建议

### 1. robots.txt 合规

系统内置 robots.txt 检查器，确保：
- 遵守网站爬取规则
- 设置合理的访问间隔
- 不采集禁止访问的内容

### 2. 速率限制

系统内置多层级限流：
- 每秒请求数
- 每分钟请求数
- 每小时请求数
- 来源级别的独立限流

### 3. 数据隔离

- 租户级别数据隔离
- 政策数据与用户知识库分离
- 敏感操作审计日志

## 扩展指南

### 添加新政策来源

```python
from app.services.policy_collector import PolicySource

new_source = PolicySource(
    name="地方税务局",
    base_url="https://地方税务局.gov.cn",
    enabled=True,
    priority=4,
    list_pattern="/api/local-policies",
    search_keywords=["地方税务", "优惠政策"]
)

policy_collector.sources.append(new_source)
```

### 自定义匹配规则

```python
from app.services.policy_retrieval_service import PolicyRetrievalService

class CustomRetrievalService(PolicyRetrievalService):
    def _calculate_match_score(self, policy_data, enterprise_profile):
        score = super()._calculate_match_score(policy_data, enterprise_profile)
        
        # 添加自定义评分逻辑
        if enterprise_profile.get("annual_revenue") > 100000000:
            score *= 1.2
        
        return min(1.0, score)
```
