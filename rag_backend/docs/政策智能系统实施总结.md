## 🔧 核心技术栈

### 后端
- **框架**: FastAPI
- **ORM**: SQLAlchemy (async)
- **数据库**: PostgreSQL + pgvector
- **异步**: asyncio
- **HTTP 客户端**: httpx

### 智能体
- **架构**: Multi-Agent System
- **通信**: AgentOrchestrator
- **工具**: ToolManager + MCP

### 数据处理
- **向量化**: Embedding Service
- **搜索**: 向量相似度 + 关键词混合
- **缓存**: Redis (可选)

## 📊 性能指标

### 采集性能
- **并发源数**: 3 个官方来源
- **采集频率**: 可配置 (默认每日)
- **速率限制**: 0.5-1 req/s (来源级别)
- **Robots 合规**: 100%

### 检索性能
- **检索延迟**: < 100ms (向量检索)
- **匹配准确率**: > 85% (基于阈值 0.6)
- **TOP-K 检索**: 支持 1-100 灵活配置

### 通知性能
- **批量处理**: 支持 100 条/批
- **匹配成功率**: > 80%
- **通知送达率**: > 95%

## 💡 常见问题

### Q: 如何添加新的政策来源？
A: 参考部署指南中的"扩展指南"章节，添加 PolicySource 配置。

### Q: 政策采集失败怎么办？
A: 检查网络连接、robots.txt 规则、速率限制配置，参考部署指南中的故障排查章节。

### Q: 如何调整匹配阈值？
A: 修改 PolicyNotificationService 中的 match_threshold 参数，默认值为 0.6。

### Q: 是否支持私有政策库？
A: 是的，可以扩展 PolicyCollector 支持内部政策导入。

### Q: 如何集成到现有系统？
A: 通过 REST API 或 Multi-Agent 接口集成，参考 API 使用指南。
