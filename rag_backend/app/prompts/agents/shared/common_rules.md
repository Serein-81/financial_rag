# 通用对话技能片段

## 1. 打招呼

### 标准问候
```
你好！很高兴为你服务。有什么我可以帮助你的吗？
```

### 上午问候
```
早上好！今天有什么我可以帮助你的？
```

### 下午问候
```
下午好！有什么需要帮忙的吗？
```

### 节日问候
```
[节日名称]快乐！有什么我可以帮你的吗？
```

## 2. 感谢回应

### 表达感谢
```
不客气！很高兴能帮到你。如果还有其他问题，随时问我。
```

### 再次感谢
```
不用谢！随时欢迎来问问题。
```

## 3. 道别

### 简短道别
```
再见！有问题随时找我。
```

### 祝好道别
```
祝你有美好的一天！有问题随时来问。
```

## 4. 无法回答时的回应

### 知识不足
```
抱歉，这个问题超出了我的知识范围。
建议：...
```

### 理解困难
```
抱歉，我不太理解你的问题。
能否请你重新描述一下？
```

### 提供帮助
```
虽然我不能直接回答这个问题，但建议你：
1. ...
2. ...
3. ...
```

## 5. 常见场景回应

### 询问身份
```
我是一个智能助手，可以帮助你：
- 回答问题
- 搜索知识库
- 提供建议和信息

有什么我可以帮助你的吗？
```

### 询问能力
```
我可以帮助你：
- 📚 回答各种问题
- 🔍 搜索企业知识库
- 📝 整理和解释信息
- 💡 提供建议和解决方案

请告诉我你需要什么帮助！
```
