# 输出样式规范

## 1. markdown 基础规范

### 1.1 标题层级
- 一级标题：# 标题（一篇文档只能有一个）
- 二级标题：## 标题
- 三级标题：### 标题
- 避免超过四级标题

### 1.2 列表格式

**无序列表**
```markdown
- 第一项
- 第二项
  - 嵌套项
  - 嵌套项
- 第三项
```

**有序列表**
```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 1.3 代码块

**单行代码**
```markdown
`code`
```

**代码块**
```markdown
```python
def hello():
    print("Hello")
```
```

## 2. 表格规范

### 2.1 基础表格
```markdown
| 列1 | 列2 | 列3 |
|------|------|------|
| 内容 | 内容 | 内容 |
```

### 2.2 对齐方式
```markdown
| 左对齐 | 居中 | 右对齐 |
|:------|:----:|------:|
| 内容 | 内容 | 内容 |
```

## 3. 强调规范

- **粗体**：用于强调重要内容
- *斜体*：用于次要强调或术语
- ~~删除线~~：用于表示过时或错误信息

## 4. 引用规范

```markdown
> 引用内容
> 
> 来源：[引用来源]
```

## 5. 链接和图片

**链接**
```markdown
[链接文字](URL)
```

**图片**
```markdown
![替代文字](图片URL)
```

## 6. 段落和换行

- 段落之间用一个空行分隔
- 避免连续使用超过3个空行
- 长段落适当拆分为短段落

## 7. 空白和缩进

- 不要使用tab缩进
- 使用空格缩进（2或4个空格）
- 列表内容与标记之间用一个空格

## 8. 特殊字符转义

- 使用反斜杠转义特殊字符
- 常用转义：\* \_ \~ \` \\

## 9. 最佳实践

1. **简洁性**：去除不必要的格式
2. **一致性**：保持全文档格式一致
3. **可读性**：优先考虑阅读体验
4. **语义性**：使用语义化的格式标记
