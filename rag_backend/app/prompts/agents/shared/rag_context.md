# RAG 检索上下文提示词

## 1. 上下文格式

### 1.1 基础上下文

```
## 检索结果

### 来源：{source}
### 相关度：{relevance_score}
### 内容：
{content}

---
```

### 1.2 批量检索结果

```
## 检索结果（共 {count} 条）

{% for item in results %}
### {loop.index}. {item.title}
**来源**: {item.source}
**相关度**: {item.score}

{item.content}

{% if not loop.last %}
---
{% endif %}
{% endfor %}

## 检索摘要
- 共检索到 {count} 条相关信息
- 最相关的 {top_n} 条已列出
- 如需更多信息，请调整查询关键词
```

## 2. 上下文标记

### 2.1 重要性标记

- **[高]** - 高度相关内容，直接相关
- **[中]** - 中等相关内容，供参考
- **[低]** - 低相关，仅边缘相关

### 2.2 置信度标记

- **[确定]** - 信息来源可靠，事实明确
- **[可能]** - 根据上下文推断，可能准确
- **[待验证]** - 信息不确定，需要进一步核实

### 2.3 局限性标记

- **[注意]** - 需要注意的异常或限制
- **[警告]** - 可能存在问题的信息
- **[仅供参考]** - 仅供参考，不作为依据

## 3. 上下文合并规则

### 3.1 优先级
1. 高相关度内容优先
2. 确定性强的事实优先
3. 来源可靠的内容优先

### 3.2 去重规则
- 相同内容只保留一条
- 保留置信度最高的版本
- 标注重复内容的来源

### 3.3 冲突处理
- 多个来源冲突时，标注冲突
- 按来源可靠性排序
- 建议用户核实关键信息

## 4. 上下文长度控制

### 4.1 短上下文（<500字）
直接包含所有内容

### 4.2 中等上下文（500-2000字）
- 摘要+详细内容
- 可折叠的详细内容

### 4.3 长上下文（>2000字）
- 简短摘要
- 关键信息列表
- 完整内容链接或引用

## 5. 上下文质量检查

### 5.1 检查清单
- [ ] 是否包含足够的信息回答问题？
- [ ] 来源是否可靠？
- [ ] 是否有明显的信息缺失？
- [ ] 是否需要补充更多检索？

### 5.2 质量评分
- 信息完整性：{score_1}/10
- 来源可靠性：{score_2}/10
- 内容准确性：{score_3}/10
- 总体质量：{score_avg}/10
