# Output Agent 输出格式规范

> **版本**: 1.0.0
> **用途**: 统一管理所有智能体输出的格式规范，为 OutputAgent 提供标准化的格式参考
> **适用范围**: synthesis.md, final_output.md, deep_review.md 等所有输出相关提示词

---

## 1. 长度约束

| 约束项 | 最小值 | 最大值 | 适用场景 |
|--------|--------|--------|----------|
| 总字符数 | 500 | 2500 | 综合报告 |
| 总字符数 | 200 | 800 | 快速回答 |
| 段落字符数 | 50 | 150 | 所有场景 |
| 列表项字符数 | 30 | 80 | 所有场景 |
| 标题字符数 | 5 | 20 | 所有场景 |

---

## 2. Markdown 格式规范

### 2.1 标题层级

```markdown
## 一级标题（报告标题，20字符以内）
### 二级标题（章节标题，15字符以内）
#### 三级标题（子章节，15字符以内）
```

### 2.2 标题规则

- 仅使用 1-3 级标题
- 禁止超过 3 级嵌套
- 标题应简洁明了，避免冗长

### 2.3 列表规范

#### 无序列表
```markdown
- 要点1：详细描述，不要截断
- 要点2：完整表达，包含足够信息
```

#### 有序列表
```markdown
1. 第一步：具体操作
2. 第二步：具体操作
3. 第三步：具体操作
```

### 2.4 加粗强调

```markdown
**重点内容**：详细说明
**风险提示**：具体描述
```

## 3. 结构模板

### 3.1 综合报告模板

```markdown
## [报告标题]

[开头段落]：友好回应用户，表达理解。如有数据缺失需清晰说明。

### 一、[第一部分主题]

[段落内容]：详细说明本部分内容，50-150字符。

**子要点**：
- 要点1：详细描述
- 要点2：详细描述

### 二、[第二部分主题]

[段落内容]：详细说明本部分内容。

**推荐列表形式**：
- **类别1**：详细描述
- **类别2**：详细描述

### 三、[第三部分主题]

[详细建议或总结]

> 💡 温馨提示或下一步建议
```

### 3.2 快速回答模板

```markdown
[直接回答，简洁明了]

**关键要点**：
- 要点1
- 要点2
- 要点3

> 💡 建议（如有）
```

## 4. Emoji 使用规范

### 4.1 推荐 Emoji

| Emoji | 用途 | 位置 |
|-------|------|------|
| 📊 | 数据、图表相关 | 标题旁 |
| 💡 | 提示、建议 | 段落结尾 |
| ⚠️ | 警告、注意 | 风险提示 |
| ✅ | 成功、完成 | 正面结果 |
| 📋 | 清单、列表 | 列表标题 |
| 📌 | 重点标记 | 内容旁 |

### 4.2 Emoji 禁止规则

- ❌ 禁止：在表格单元格中使用 emoji
- ❌ 禁止：连续堆砌 emoji（超过5个）
- ❌ 禁止：过度使用 emoji
- ❌ 禁止：在代码块中使用 emoji

---

## 5. 格式禁止项

### 5.1 禁止的格式

- ❌ 空表格
- ❌ 只有分隔线的表格
- ❌ 数据不足3行的表格
- ❌ 冗长的背景描述（超过3句）
- ❌ 重复相同观点
- ❌ 段落或列表项被截断
- ❌ 内容过于紧凑，没有换行
- ❌ 机械化开头（如"根据检索结果"）

### 5.2 表格使用条件

**仅在以下情况使用表格**：
1. 输入内容中包含具体数据表格
2. 数据完整且有意义
3. 表格行数不少于3行

**其他情况使用列表代替**。

---

## 6. 质量检查清单

### 输出前必须检查：

- [ ] 每段话是否表达完整意思（50-150字符）
- [ ] 列表项是否内容充实（30-80字符）
- [ ] 表格每行是否信息完整
- [ ] 段落之间是否有适当换行
- [ ] 内容是否流畅易读
- [ ] 标题层级是否正确（1-3级）
- [ ] Emoji 使用是否适量（不超过5个）
- [ ] 是否避免了禁止的格式

---

## 7. 输出类型定义

| 类型 | 用途 | 字符数 | 结构复杂度 |
|------|------|--------|------------|
| `summary` | 简短总结 | 500-1000 | 简单 |
| `detailed` | 详细报告 | 1500-2500 | 复杂 |
| `actionable` | 行动导向 | 1000-2000 | 中等 |
| `quick` | 快速回答 | 200-500 | 最简 |

---

## 8. 格式变量说明

提示词中可使用的格式相关变量：

| 变量名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `{output_type}` | string | 输出类型 | "summary", "detailed" |
| `{min_chars}` | int | 最小字符数 | 500 |
| `{max_chars}` | int | 最大字符数 | 2500 |
| `{max_paragraphs}` | int | 最大段落数 | 5 |
| `{use_emoji}` | bool | 是否使用 emoji | true |
| `{include_toc}` | bool | 是否包含目录 | false |
| `{target_audience}` | string | 目标受众 | "expert", "novice" |
