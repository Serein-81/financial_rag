## 3. 合成策略提示词 (synthesis)

请将以下专家分析结果整合成一份**清晰完整、美观专业**的综合报告。

【用户问题】
{user_query}

【专家分析结果】
{specialist_results}

### 📐 长度和内容要求
- **输出总长度**：1500-2500 字符
- **段落长度**：每段 50-150 字符，完整表达一个意思
- **列表项**：每项 30-80 字符，内容充实完整
- **表格行数**：根据实际需要，不强行限制，但每行要完整表达信息

### 🎯 核心要点
1. **开头友好**：先友好地回应用户，表达理解和感谢
2. **结构清晰**：使用多级标题组织内容，层次分明
3. **内容完整**：每段话、每个列表项都要表达完整意思，不要截断
4. **段落分隔**：段落之间要换行，保持呼吸感
5. **逻辑流畅**：按重要性排序，逻辑连贯

### 📋 推荐结构

```
## [报告标题]

[开头段落]：友好地回应用户，表达理解。如果检测到数据缺失，要清晰说明。

### 一、[第一部分主题]

[段落内容]：详细说明本部分内容，要完整流畅。

[可选：列表或表格]
- 要点1：详细描述，不要截断
- 要点2：完整表达，包含足够信息

### 二、[第二部分主题]

**推荐使用列表形式展示详细信息**：

**风险类型1**：
- 典型表现：详细描述，避免过于简短
- 建议措施：具体可操作的建议

**风险类型2**：
- 典型表现：详细描述，包含足够信息
- 建议措施：具体可操作的建议

**⚠️ 重要提醒**：
- **严格禁止生成表格**：除非输入内容中包含具体数据表格，否则不要生成任何表格
- **必须使用列表**：当没有具体数据时，使用列表形式代替表格
- 列表项格式：`**标题**：` + 换行 + `- 详细描述1` + 换行 + `- 详细描述2`
- **禁止**：空表格、只有分隔线的表格、数据不足3行的表格

### 三、[第三部分主题]

[详细建议或说明，内容要充实]

> 💡 [温馨提示或下一步建议]
```

### ✨ Emoji 使用指南
- 根据内容需要适当使用，不要刻意限制
- 放在标题旁增强可读性
- 放在注意事项或建议旁引起注意
- 推荐：`📊` `💡` `⚠️` `✅` `📋` `📌`
- 禁止：在表格单元格中使用 emoji
- 禁止：连续堆砌 emoji

### ❌ 禁止事项
- 冗长的背景描述（超过3句）
- 重复相同观点
- 段落或列表项被截断
- 内容过于紧凑，没有换行
- 表格单元格内容过于简短（如"未提供"三个字）
- 过度使用 emoji（超过5个）

### ✅ 质量检查清单
在输出前，请检查：
- 每段话是否表达完整意思
- 列表项是否内容充实（至少20个字符）
- 表格每行是否信息完整
- 段落之间是否有适当换行
- 内容是否流畅易读

**请直接输出整合后的 Markdown 报告，不要添加任何说明文字。**

请快速审查以下输出是否有明显问题。

【用户问题】
{user_query}

【AI 输出】
{output}

【快速检查项】
1. 是否为空或过短（<10字）？
2. 是否包含敏感信息（密码、密钥等）？

请返回 JSON：
```json

    "issue_type": "sensitive|internal|empty|mechanical|other|none",
    "quick_score": 0-10
}
```

## 5. 深度审查提示词 (deep_review)

请深度审查以下 AI 回答的质量。

【用户问题】
{user_query}

【AI 回答】
{output}

【深度审查标准】
1. 相关性（25%）：回答是否针对用户问题？是否在回答用户真正想知道的内容？
2. 完整性（25%）：回答是否涵盖了问题的各个方面？是否提供了足够的信息？
3. 准确性（25%）：回答中的信息是否正确？是否有事实性错误？
4. 可读性（15%）：回答是否清晰易懂？格式是否良好？
5. 安全性（10%）：是否包含敏感信息？语气是否合适？

【审查要求】
- 如果发现任何敏感信息或内部标记，直接返回 0-4 分
- 如果回答完全空或不相关，直接返回 0-4 分
- 开头如果有"抱歉，我..."、"根据显示..."等机械化表述，扣 2 分
- 如果没有问题，可以给出 7-10 分

【返回格式】
请严格返回以下 JSON 格式，不要有任何额外内容：
```json
{
    "is_approved": true或false,
    "score": 0.0到10.0的数字,
    "issues": ["问题1的具体描述", "问题2的具体描述"],
    "suggestion": "具体的改进建议，应该如何修改这段回答"
}
```
