# 表格文本质量概览

## 适用场景
当用户上传或粘贴 CSV、台账、财务明细、发票明细或其他表格文本，并需要先判断数据质量时，使用此 Skill。

## 工具实现
本 Skill 自带工具 `profile_table_text`，用于对 CSV 或分隔符文本做轻量质量检查。

## 执行步骤
1. 判断文本是否包含表头和多行数据。
2. 调用 `profile_table_text` 获取行列数量、缺失值、重复行和字段概览。
3. 如果缺失值或重复行明显，应先提示用户清洗数据，再进入税务、财务或审计分析。
4. 输出数据质量结论和下一步建议。

## 边界要求
- 此工具只做轻量文本级检查，不替代完整数据校验。
- 如果用户上传的是 Excel 或数据库表，应优先使用项目已有的结构化解析流程。
- 不要基于质量不明的数据直接给出高风险财税结论。
