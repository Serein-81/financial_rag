# 企业知识库检索

## 适用场景
当用户询问内部文档、已上传文件、公司制度、知识库内容或企业历史资料时，使用此 Skill。

## 执行步骤
1. 当问题范围不清晰时，先明确目标知识库、文档或检索范围。
2. 对企业内部事实类问题，优先使用 `search_enterprise_knowledge`。
3. 当用户询问有哪些文档可用，或检索范围不明确时，使用 `list_knowledge_documents`。
4. 回答必须基于检索到的证据，并在可用时标注来源文档。
5. 如果证据不足，明确说明知识库中没有足够可靠的信息。

## 边界要求
- 不要编造内部制度、流程或文档内容。
- 不要把公网信息当作企业内部知识。
- 不要暴露用户无权查看的私有文档元数据。
