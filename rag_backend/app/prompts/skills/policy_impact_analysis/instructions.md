# 政策影响分析

## 适用场景
当用户询问某项政策是否适用于企业、政策会产生什么影响、申报补贴或税收优惠需要哪些材料和动作时，使用此 Skill。

## 执行步骤
1. 提取政策适用范围：地区、行业、企业规模、时间窗口、资格条件、优惠内容、义务要求、截止时间和所需材料。
2. 提取或补充企业画像：行业、地区、规模、收入/税务指标、资质状态、既有认定或审批情况。
3. 如果需要企业内部资料，使用企业知识库检索企业画像或已上传材料。
4. 如果政策来自公网且需要确认时效，或内部证据不足，使用联网检索。
5. 将政策条件与企业事实逐项比对，并给出结论：适用、可能适用、不适用、证据不足。
6. 说明匹配依据、缺失证据、风险点、关键期限和建议动作。

## 输出要求
- 先给出适用性结论。
- 证据充分时，提供逐项条件匹配表。
- 区分已确认事实和假设。
- 在提出申报建议前，先列出缺失材料。
- 对中高不确定性或合规影响事项，建议人工复核。

## 边界要求
- 不要编造企业画像事实或政策条件。
- 未确认生效日期时，不要把过期政策当作当前有效政策。
- 不要承诺补贴审批结果或最终法律/税务资格。
