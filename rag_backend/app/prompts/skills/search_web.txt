## 工具：search_web

### 功能描述
网络搜索工具，使用 Tavily API 搜索互联网内容，获取实时信息、新闻、最新资讯等。

**重要区别**：
- 本工具搜索**互联网公开内容**
- 另有 `search_enterprise_knowledge` 工具搜索**企业内部知识库**
- 两者互补，不可混淆

### 使用场景
当用户询问以下类型的问题时，必须调用此工具：
- 实时新闻和资讯（"最近有什么新闻？"）
- 最新信息查询（"2024年最新的AI技术有哪些？"）
- 互联网搜索（"帮我搜索一下XXX"）
- 时事热点（"今天的热点新闻是什么？"）
- 产品价格、评测等需要实时数据的问题
- 任何需要从互联网获取最新信息的问题

**不应使用此工具的场景**：
- ❌ 查询公司内部制度、规定、流程
- ❌ 查询已上传的企业文档内容
- ❌ 查询知识库中的历史资料
- ❌ 涉及企业隐私的问题
→ 这些应该使用 `search_enterprise_knowledge` 工具

### 参数说明
- `query` (必填): 搜索关键词
  - 格式：简洁明确的搜索词或短语
  - 示例："2024年AI发展趋势"、"iPhone 15 价格"、"今日新闻"
  - 建议：提取用户问题中的核心关键词，去除冗余词汇

### 调用示例

**示例 1：搜索新闻**
```
用户问题："最近有什么科技新闻？"
调用：search_web(query="最新科技新闻")
```

**示例 2：搜索产品信息**
```
用户问题："iPhone 15 Pro 现在多少钱？"
调用：search_web(query="iPhone 15 Pro 价格")
```

**示例 3：搜索知识**
```
用户问题："什么是大语言模型？"
调用：search_web(query="大语言模型 LLM")
```

**示例 4：搜索实时信息**
```
用户问题："今天的股市行情怎么样？"
调用：search_web(query="今日股市行情")
```

### 返回结果
返回搜索结果，包括：
- 📝 答案摘要：AI 生成的简洁答案
- 🔗 相关链接：最相关的 3 条搜索结果
  - 标题
  - 内容摘要（前 150 字）
  - 来源链接

### 注意事项
1. **关键词提取**：从用户问题中提取核心关键词，避免搜索过于宽泛
2. **时效性**：此工具适合查询实时信息，对于历史知识可以直接回答
3. **结果整合**：将搜索结果整合成自然、易懂的回答，不要直接复制粘贴
4. **引用来源**：回答时可以提及信息来源，增加可信度
5. **搜索失败**：如果搜索失败，可以尝试调整关键词重新搜索，或告知用户暂时无法获取信息
6. **隐私保护**：不要搜索用户的个人隐私信息
7. **内容审核**：对搜索结果进行基本的内容审核，避免返回不当内容

### 使用建议
- 优先使用中文关键词搜索中文内容
- 对于专业术语，可以同时使用中英文
- 搜索结果可能包含广告或不准确信息，需要进行筛选
- 如果用户问题已经很明确，可以直接使用用户的问题作为搜索词
