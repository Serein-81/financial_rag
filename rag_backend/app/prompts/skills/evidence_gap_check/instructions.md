# 证据缺口检查

## 适用场景
当用户需要判断当前材料是否足够支撑政策申报、合同审查、税务复核、审计检查或合规结论时，使用此 Skill。

## 工具实现
本 Skill 自带工具 `analyze_evidence_gaps`，用于对比“所需证据清单”和“已提供材料清单”，输出缺失项、覆盖率、风险等级和补充建议。

## 执行步骤
1. 先整理当前任务所需证据清单。
2. 再整理用户已经提供或系统已经检索到的材料清单。
3. 调用 `analyze_evidence_gaps` 对比两类清单。
4. 如果缺失关键材料，不要给出最终合规、税务、政策或法务结论。
5. 输出缺失材料、影响、优先补充顺序和下一步动作。

## 边界要求
- 不要把“未提供”解释成“不存在”。
- 不要用推测材料替代真实证据。
- 对高风险缺口，应建议人工复核。
