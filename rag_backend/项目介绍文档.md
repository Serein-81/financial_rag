# 财税法务多智能体审查系统 - 项目介绍文档

## 📋 项目概述

### 项目名称
**智能财税与法务合规审查引擎 - 多智能体系统**

### 项目定位
这是一个基于多智能体架构的企业级财税法务合规审查系统，通过AI技术自动化处理财务报表审查、税务合规检查、合同审查等业务场景，为企业提供专业、高效、安全的合规审查服务。

### 核心价值
- **专业化分工**：财务、税务、法务三大专家智能体协同工作
- **企业级安全**：严格的多租户数据隔离，确保企业数据安全
- **智能化审查**：自动识别风险点，提供专业建议和法律依据
- **全流程覆盖**：从文档解析到报告生成的完整审查流程

## 🎯 业务场景与功能

### 核心业务场景

#### 1. 财务报表审查
**业务价值**：自动化财务报表合规性检查，提高审查效率和准确性

**功能特性**：
- **完整性检查**：验证财务报表必填项是否齐全
- **平衡性验证**：资产负债表平衡性自动校验
- **合理性分析**：异常数据识别和风险预警
- **指标计算**：自动计算财务健康度指标
- **趋势分析**：同比环比变化分析

**支持文档类型**：
- 资产负债表（Excel/PDF）
- 利润表（Excel/PDF）
- 现金流量表（Excel/PDF）
- 财务报告（Word/PDF）

#### 2. 税务合规审查
**业务价值**：确保税务申报准确性，降低税务风险

**功能特性**：
- **增值税审查**：税率、进项税额、销项税额验证
- **企业所得税审查**：应纳税所得额、税前扣除项目检查
- **个人所得税审查**：工资薪金、劳务报酬合规性
- **税收优惠检查**：政策适用性验证
- **风险识别**：虚开发票、偷税漏税风险预警

**支持文档类型**：
- 增值税申报表（PDF/Excel）
- 企业所得税申报表（PDF/Excel）
- 税务登记证（图片/PDF）
- 发票扫描件（图片）

#### 3. 法务合同审查
**业务价值**：识别合同法律风险，保障企业合法权益

**功能特性**：
- **合同要素检查**：主体、标的、价款、履行期限完整性
- **必备条款验证**：违约责任、争议解决、保密条款
- **风险条款识别**：不平等条款、霸王条款预警
- **法律合规检查**：是否违反相关法律法规
- **行业规范验证**：特定行业合规要求检查

**支持文档类型**：
- 劳动合同（Word/PDF/扫描件）
- 商业合同（Word/PDF/扫描件）
- 投资协议（Word/PDF）
- 保密协议（Word/PDF）

#### 4. 综合合规审查
**业务价值**：跨领域综合分析，发现隐蔽风险

**功能特性**：
- **跨领域关联分析**：财务、税务、法务数据交叉验证
- **关联交易识别**：通过知识图谱发现隐蔽关联关系
- **冲突检测**：不同专业领域结论的一致性检查
- **证据溯源**：每个结论都有明确的法律依据和证据支撑
- **风险等级评估**：综合风险评分和分级预警

### 业务流程

```
用户上传文档 → 文档类型识别 → 多智能体协调器 → 数据摄入管道
                                                    ↓
财务专家 ← 并行专业审查 → 税务专家 → 法务专家
   ↓           ↓           ↓
   → 反思质检 ← 发现冲突? → 重做审查（如有冲突）
        ↓
   报告生成 → 多格式输出
```

#### 多智能体协同机制

**核心设计理念**：
1. **全局状态管理**：所有Agent共享AuditState，避免数据重复传递
2. **专业化分工**：每个Agent专注特定领域，提高专业性
3. **反思机制**：独立的质检Agent检测冲突，确保结果一致性
4. **工具化设计**：文档解析、知识检索等作为工具而非Agent

**协同流程**：

#### 3. 财务专家 (finance_specialist.py)

**专业能力**：财务报表审查和风险识别

```python
class FinanceSpecialist(BaseSpecialistAgent):
    """财务审查智能体"""
    
    async def perform_audit(self, state: AuditState) -> List[Finding]:
        findings = []
        
        # 1. 完整性检查
        completeness = await self._check_completeness(state)
        findings.extend(completeness)
        
        # 2. 平衡性检查
        balance = await self._check_balance(state)
        findings.extend(balance)
        
        # 3. 关联交易分析（调用Neo4j动态查询）
        related_party = await self._analyze_related_party_transactions(state)
        findings.extend(related_party)
        
        return findings
    
    async def _check_balance(self, state: AuditState) -> List[Finding]:
        """资产负债表平衡性检查"""
        # 从全局状态读取财务数据
        financial_data = state.get('parsed_data', {}).get('financial_statements', {})
        
        assets = financial_data.get('total_assets', 0)
        liabilities = financial_data.get('total_liabilities', 0)
        equity = financial_data.get('total_equity', 0)
        
        if abs(assets - (liabilities + equity)) > 0.01:
            return [Finding(
                type='error',
                category='balance_check',
                message='资产负债表不平衡',
                evidence={'assets': assets, 'liabilities_equity': liabilities + equity},
                legal_basis='企业会计准则基本准则',
                risk_level='high'
            )]
        
        return []
```

#### 4. 反思专家 (reflection_specialist.py)

**核心职责**：跨领域冲突检测和证据验证

```python
class ReflectionSpecialist(BaseSpecialistAgent):
    """反思专家 - 质量检查和冲突检测"""
    
    async def reflect(self, state: AuditState) -> AuditState:
        """执行反思检查"""
        
        # 1. 跨领域冲突检测
        conflicts = await self._detect_conflicts(state)
        
        # 2. 证据溯源检查
        evidence_gaps = await self._validate_evidence(state)
        
        # 3. 置信度评估
        confidence_scores = await self._evaluate_confidence(state)
        
        # 4. 决定是否需要重做
        need_rework = len(conflicts) > 0 or len(evidence_gaps) > 0
        
        # 5. 更新全局状态
        state.update({
            'conflicts': conflicts,
            'evidence_gaps': evidence_gaps,
            'confidence_scores': confidence_scores,
            'need_rework': need_rework
        })
        
        return state
    
    async def _detect_conflicts(self, state: AuditState) -> List[Conflict]:
        """检测跨领域冲突"""
        conflicts = []
        
        # 示例：财务说"营业收入"，法务说"借款"
        finance_findings = state.get('finance_findings', [])
        legal_findings = state.get('legal_findings', [])
        
        for f_finding in finance_findings:
            if '营业收入' in f_finding.message:
                for l_finding in legal_findings:
                    if '借款' in l_finding.message:
                        conflicts.append(Conflict(
                            type='classification_conflict',
                            agent1='finance',
                            agent2='legal',
                            description='财务认为是营业收入，法务认为是借款',
                            resolution_needed=True
                        ))
        
        return conflicts
```

```python
class TenantContextMiddleware(BaseHTTPMiddleware):
    """租户上下文中间件"""
    
    async def dispatch(self, request: Request, call_next):
        # 1. 从JWT token提取租户ID
        tenant_id = await self._extract_tenant_id(request)
        
        # 2. 设置租户上下文
        tenant_context.set(tenant_id)
        
        # 3. 为数据库会话设置租户过滤
        async with get_db_session() as session:
            await session.execute(
                text("SET app.current_tenant_id = :tenant_id"),
                {"tenant_id": tenant_id}
            )
        
        # 4. 执行请求
        response = await call_next(request)
        
        # 5. 记录审计日志
        await self._log_tenant_access(tenant_id, request)
        
        return response
```

```python
# 自定义审查规则
from app.multi_agent_system.agents import FinanceSpecialist

class CustomFinanceSpecialist(FinanceSpecialist):
    async def load_custom_rules(self):
        """加载自定义审查规则"""
        self.custom_rules = [
            {
                "name": "现金流异常检查",
                "condition": "cash_flow_ratio < 0.1",
                "severity": "high",
                "message": "现金流比率过低，存在流动性风险"
            }
        ]
    
    async def apply_custom_rules(self, financial_data):
        """应用自定义规则"""
        findings = []
        for rule in self.custom_rules:
            if self.evaluate_condition(rule["condition"], financial_data):
                findings.append(Finding(
                    type="warning",
                    message=rule["message"],
                    severity=rule["severity"]
                ))
        return findings
```
