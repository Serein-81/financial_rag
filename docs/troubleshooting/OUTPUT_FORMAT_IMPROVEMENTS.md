# 输出格式优化 - 输出智能体提示词改善

## 📋 优化日期
2026-04-11

## 🎯 问题诊断

### 原始问题
用户反馈输出"非常紧凑"，从实际输出看：
- 表格格式混乱，内容被截断（如"立即导入增值税/"后面丢失）
- 内容过于简洁，信息不完整
- 段落之间没有适当间距
- 列表项内容简短（如"未提供"）

### 根本原因
输出智能体的提示词要求过于"简洁"：
- **长度限制**：800-1500字符（太短）
- **每个要点**：不超过50字符（太短）
- **表格行数**：最多6行（限制过严）
- **示例格式**：过于简洁，内容不完整

---

## ✅ 优化措施

### 1. 优化 system_prompt.txt

#### 核心原则变更
```diff
- 1. **简洁专业**：用最精炼的语言表达核心观点
+ 1. **清晰专业**：用清晰流畅的语言表达核心观点，语句完整通顺

- 3. **数据驱动**：用数据和事实支撑结论
+ 3. **信息完整**：确保内容完整，不要截断，让用户能完整理解

- 4. **美观适度**：合理使用格式和 emoji，但不过度装饰
+ 4. **美观易读**：合理使用格式和 emoji，让报告赏心悦目
```

#### 长度控制优化
```diff
- - **总长度**：控制在 800-1500 字符以内
- - **段落长度**：每个段落不超过 100 字符
- - **表格行数**：最多 5-6 行关键数据
+ - **总长度**：控制在 1500-2500 字符之间
+ - **段落长度**：每个段落 50-150 字符，表达完整意思
+ - **表格行数**：根据实际内容需要，不强行限制
+ - **列表项**：每项 30-80 字符，表达完整意思
```

#### 新增详细规范

**标题规范**：
- 一级标题：报告主题，简洁有力（8-15字）
- 二级标题：各部分主题，清晰明确（8-20字）
- 三级标题：小节主题，精准概括（8-15字）

**段落规范**：
- 每段表达完整意思，不要因为追求简短而截断
- 使用换行分隔不同内容块
- 段落之间留适当空行

**表格规范**：
- 表头使用粗体，格式：| 项目 | 内容 |
- 使用3个以上短横线分隔：|------|------|
- 每行完整表达一个信息点
- 单元格内容不要太短，确保可读性

#### 禁止事项新增
```diff
+ - ❌ 表格单元格内容过于简短（要完整表达）
+ - ❌ 段落或列表项被截断（要表达完整意思）
+ - ❌ 内容过于紧凑（段落之间要换行）
```

#### 新增质量标准
```markdown
## 质量标准
- ✅ 每段话表达完整意思
- ✅ 表格每行信息完整
- ✅ 列表项内容充实
- ✅ 结构层次分明
- ✅ 阅读体验舒适
```

### 2. 优化 synthesis_prompt.txt

#### 标题和核心要点优化
```diff
- 请将以下专家分析结果整合成一份**简洁专业**的综合报告。
+ 请将以下专家分析结果整合成一份**清晰完整、美观专业**的综合报告。

- 1. **开头直击主题**：第一行就要回应用户问题
+ 1. **开头友好**：先友好地回应用户，表达理解和感谢

- 2. **提取精华**：只保留最关键的结论和数据
+ 2. **结构清晰**：使用多级标题组织内容，层次分明

+ 3. **内容完整**：每段话、每个列表项都要表达完整意思，不要截断
+ 4. **段落分隔**：段落之间要换行，保持呼吸感
```

#### 长度和内容要求优化
```diff
- - **输出总长度**：800-1500 字符
- - **每个要点**：不超过 50 字符
- - **表格行数**：最多 6 行
+ - **输出总长度**：1500-2500 字符
+ - **段落长度**：每段 50-150 字符，完整表达一个意思
+ - **列表项**：每项 30-80 字符，内容充实完整
+ - **表格行数**：根据实际需要，不强行限制，但每行要完整表达信息
```

#### 新增质量检查清单

## 质量检查清单
