## 📝 常见问题排查

### 问题1：输出仍然包含空表格
**可能原因**：
1. 后端服务未重启，提示词未生效
2. LLM 缓存了旧的提示词

**解决方案**：
```bash
# 重启后端服务
cd d:\Python\Codebase\My_rag\rag_backend
pkill -f uvicorn
uvicorn app.main:app --reload
```

### 问题2：输出长度过短
**可能原因**：
- max_tokens 参数设置过低

**解决方案**：
在 `output_agent.py` 中调整 max_tokens 参数：
```python
max_tokens = 4000  # 增大到 4000
```

### 问题3：列表项过少
**可能原因**：
- LLM 生成的内容不够详细

**解决方案**：
在 `system_prompt.txt` 中强化列表要求：
```markdown
**列表规范**：
- 每个主题至少包含 3 个列表项
- 每个列表项至少 30 字符
- 使用详细描述，避免过于简短
```
