## 🎯 使用说明

### 基本使用
1. **进入页面**: 点击左侧菜单"税务提交"
2. **提交报告**: 点击"提交报告" tab
3. **拖拽上传**: 将文件拖到上传区域或点击选择
4. **选择税种**: 从下拉菜单中选择税务类型
5. **填写期间**: 选择税务年度和月份
6. **提交**: 点击"提交报告"按钮

### 工作流状态
1. **数据验证** - 验证文件格式和内容
2. **获取财务数据** - 从数据库获取相关数据
3. **税务计算** - 执行税务计算
4. **风险评估** - 评估税务风险
5. **人工审核** (如有高风险) - 人工审核风险项
6. **保存结果** - 保存分析结果

### 查看结果
1. 完成后自动跳转到"报告列表"
2. 点击"查看"按钮查看详情
3. 可以看到 AI 分析结果、风险评分等

## ⚠️ 注意事项

### 1. 后端必须运行
工作流依赖后端的 SSE 推送功能，必须先启动后端服务。

### 2. 浏览器缓存
如果页面显示异常，按 `Ctrl + Shift + R` 强制刷新。

### 3. 权限要求
需要登录后才能使用税务提交功能。

## 🐛 常见问题

### Q: 页面一直显示加载中？
**A**: 检查后端服务是否启动，浏览器控制台是否有错误。

### Q: 工作流没有反应？
**A**: 检查 SSE 连接是否正常，查看浏览器控制台。

### Q: 审核对话框不出现？
**A**: 只有检测到高风险项时才会出现审核对话框。

## 📝 技术细节

### 组件导入
```typescript
import TaxSubmissionWorkflow from '@/components/TaxSubmissionWorkflow.vue'
```

### 事件处理
```typescript
const handleWorkflowComplete = () => {
  ElMessage.success('税务提交处理完成！')
  loadReportList()
  loadStatistics()
  activeTab.value = 'list'
}

const handleWorkflowError = (error: string) => {
  ElMessage.error('处理失败: ' + error)
}

const handleWorkflowCancel = () => {
  ElMessage.info('已取消处理')
}
```

### API 调用
工作流组件内部会自动调用：
- `POST /api/v1/tax-reports/` - 上传报告
- `GET /api/v1/workflow-events/stream/{workflow_id}` - SSE 流
- `POST /api/v1/workflow-events/human-review` - 提交审核
