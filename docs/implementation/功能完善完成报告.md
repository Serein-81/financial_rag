## 📋 详细实现内容

### 1. PDF导出功能

#### 税务分析报告PDF导出
- **文件**: `app/services/pdf_export_service.py`
- **功能**: 
  - `export_tax_analysis_report()` - 生成专业税务分析报告PDF
  - 支持财务摘要、税务计算、风险评分等
- **API端点**: `GET /api/v1/tax-intelligence/report/{analysis_id}/export`

#### 财务健康报告导出
- **文件**: `app/api/v1/endpoints/financial_health.py`
- **功能**: 
  - `export_financial_health_report_pdf()` - 导出财务健康报告PDF
  - 支持异常检测、趋势分析、指标摘要
- **API端点**: `GET /api/v1/financial-health/report/export`

#### 合同审核报告导出
- **文件**: `app/api/v1/endpoints/contract_review.py`
- **功能**:
  - `export_contract_review_report_pdf()` - 导出合同审核报告PDF
  - 支持条款分析、风险评估、修改建议
- **API端点**: `GET /api/v1/contract-review/report/export`

### 2. 定时任务调度系统

#### 核心调度器
- **文件**: `app/services/task_scheduler.py`
- **功能**:
  - 任务注册、调度、执行
  - 支持多种频率: 一次性/每日/每周/每月/每季度/每年
  - 任务重试机制（默认3次）
  - 执行历史记录

#### 任务管理器
- **文件**: `app/services/task_manager.py`
- **功能**:
  - `setup_tax_reminder()` - 设置税务申报提醒
  - `setup_periodic_financial_report()` - 设置定期财务报告
  - `setup_policy_update_subscription()` - 设置政策更新推送
  - `setup_anomaly_check()` - 设置财务异常检查

#### 预定义任务
- `tax_reminder_task()` - 税务申报提醒任务
- `financial_health_report_task()` - 定期财务报告任务
- `policy_update_push_task()` - 政策更新推送任务
- `anomaly_check_task()` - 财务异常检查任务

#### 系统集成
- **文件**: `app/main.py`
- 在应用启动时自动启动调度器
- 在应用关闭时自动停止调度器

## 🚀 使用示例

### 1. 导出PDF报告
```python
# 税务分析报告
GET /api/v1/tax-intelligence/report/{analysis_id}/export

# 财务健康报告
GET /api/v1/financial-health/report/export?period_days=90

# 合同审核报告
GET /api/v1/contract-review/report/export?analysis_id=xxx
```

### 2. 设置定时任务
```python
from app.services.task_manager import task_manager

# 设置税务申报提醒
task_manager.setup_tax_reminder(
    tenant_id="xxx",
    user_id="xxx",
    tax_type="vat",
    due_date=datetime(2026, 4, 15)
)

# 设置定期财务报告
task_manager.setup_periodic_financial_report(
    tenant_id="xxx",
    user_id="xxx",
    frequency=TaskFrequency.WEEKLY
)
```

### 3. 发送通知
```python
from app.services.admin_notification_service import AdminNotificationService

service = AdminNotificationService()
await service.send_notification(
    user_id="xxx",
    title="税务提醒",
    message="您的增值税申报即将到期",
    notification_type=NotificationType.TAX_REMINDER,
    priority=NotificationPriority.HIGH
)
```

### 4. 数据源连接
```python
from app.services.data_source_manager import data_source_manager, DataSourceType

# 注册数据源
data_source_manager.register_datasource(
    name="erp_api",
    source_type=DataSourceType.REST_API,
    config={"base_url": "https://api.example.com", "headers": {...}}
)

# 查询数据
result = await data_source_manager.fetch_data(
    source_name="erp_api",
    endpoint="/api/sales",
    params={"date": "2026-04-01"}
)
```
