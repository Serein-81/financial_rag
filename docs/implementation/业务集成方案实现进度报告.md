#### 异常检测规则

```python
class FinancialAnomalyDetector:
    def detect_anomalies()  # 检测财务异常
    
    # 预定义规则
    1. 收入断崖式下跌 (revenue_drop_rule)
       - 条件: 单月收入环比下降>30%
       - 严重程度: HIGH
    
    2. 成本异常飙升 (cost_surge_rule)
       - 条件: 单月成本环比上升>20%
       - 严重程度: MEDIUM
    
    3. 现金流持续为负 (negative_cashflow_rule)
       - 条件: 连续3个月经营现金流为负
       - 严重程度: HIGH
    
    4. 回款周期延长 (extended_receivables_rule)
       - 条件: 回款周期超过行业平均150%
       - 严重程度: MEDIUM
    
    5. 毛利率持续下降 (margin_decline_rule)
       - 条件: 连续3个月毛利率下降
       - 严重程度: MEDIUM
    
    6. 资产负债率超标 (leverage_exceed_rule)
       - 条件: 超过行业安全阈值(0.7)
       - 严重程度: HIGH
```
